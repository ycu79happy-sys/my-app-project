# Note Garden

무료 PC·휴대폰 연동 배포: [쉬운 설정 안내](FREE-SETUP.md). GitHub Pages와 Supabase Free를 사용하는 정적 배포를 지원합니다. 별도 유료 서버 없이 시작할 수 있으며 서비스 무료 한도와 정책이 적용됩니다.

PC와 휴대폰 브라우저에서 같은 서버에 로그인해 사용하는 메모 앱입니다. 노트북 분류, 검색, 고정, 자동 저장, 5초 주기의 다른 기기 변경 확인, 동시 수정 충돌 감지, JSON 전체 백업과 Markdown/TXT/ZIP 가져오기를 지원합니다. UpNote의 독립적인 대체 앱이며 화면과 기능을 완전히 복제한 제품은 아닙니다.

## 실행

Node.js 24 이상이 필요합니다.

```sh
npm ci --cache /tmp/note-npm-cache
npm start
```

기본 주소는 내부 검증용 `127.0.0.1:3000`입니다. 서버 데이터는 `data/notes.sqlite`에 저장되며 Git에 포함되지 않습니다. `PORT`, `HOST`, `DATA_DIR`로 변경할 수 있습니다. PC·휴대폰 자동 동기화에는 두 기기가 접속할 수 있는 동일한 서버 배포가 필요합니다. 공개 배포에는 HTTPS 프록시, `COOKIE_SECURE=1`, 로그인 요청 속도 제한, 데이터 디렉터리의 정기 백업을 설정하세요. 현재는 이메일 인증, 비밀번호 재설정, 오프라인 편집, 첨부파일, 리치 텍스트 미리보기를 지원하지 않는 초기 구현입니다. 실제 인터넷 공개 서비스 배포는 아직 수행하지 않았습니다.

## UpNote 이전

1. UpNote에서 모든 메모를 Markdown 형식으로 내보내 원본 백업을 안전하게 보관하세요.
2. 이 앱의 `백업 가져오기`에서 `.md`, `.txt` 파일 또는 이 파일들이 포함된 `.zip`을 선택하세요.
3. 첫 번째 Markdown 제목을 메모 제목으로 사용하고, 상위 폴더를 노트북으로 사용합니다. Markdown 원문을 보존합니다. 동일 제목·내용은 중복 가져오기를 건너뜁니다.
4. 가져온 메모 수와 내용을 확인하고 `전체 백업`으로 JSON 사본을 보관하세요.

이미지·첨부파일 및 UpNote 고유 백업 형식은 지원하지 않습니다. ZIP에 포함된 미지원 파일은 제외 수로 표시합니다. 실제 사용자의 백업은 아직 제공되지 않아 이전되지 않았습니다. 가져오기는 기존 메모를 지우지 않으며, JSON 복원도 새 ID로 추가합니다. 파일은 20MB, 개별 Markdown 메모는 1MB, 일괄 가져오기는 1,000개로 제한합니다.

## 검증

```sh
npm test
```

로컬 모드 회원가입·로그인·세션, 계정 간 데이터 격리, 메모 저장·조회·수정 충돌·삭제, 로그아웃을 실제 HTTP 요청으로 검사합니다. 무료 클라우드 어댑터는 이메일 인증 대기, 토큰 갱신, 버전 충돌, 페이지별 조회를 모의 응답으로 검사합니다. 실제 Supabase 프로젝트는 아직 연결하지 않았습니다.
