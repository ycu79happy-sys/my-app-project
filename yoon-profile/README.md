# 윤철언 자기소개 사이트

`index.html`을 두 번 클릭하면 인터넷 연결이나 별도 설치 없이 브라우저에서 열립니다.

- 자기소개, AI 교육생 소개, 배움의 기록 공간을 제공합니다.
- 컴퓨터와 휴대폰 화면에 맞게 배치가 바뀝니다.
- 소개 문구를 바꾸려면 `index.html`을 편집합니다.
- 배움의 기록은 현재 안내 문구만 있으며 게시물 작성·저장 기능은 없습니다.
- 외부 서비스 연결, 개인정보 수집, 로그인 기능은 없습니다.
- 인터넷 공개는 진행하지 않았습니다.

자기소개 버튼과 상단 자기소개 메뉴는 별도 페이지인 about.html로 이동합니다. 첫 화면으로 돌아오는 링크가 제공됩니다. 두 페이지는 style.css 디자인 파일을 함께 사용하므로 세 파일을 같은 폴더에 보관하세요.
